# DAA Lab Assignment – Algorithms Analysis

This repository contains complete laboratory work for the course **Design and Analysis of Algorithms (DAA)**.  
The project includes implementation of classical algorithms, performance measurement, and analysis of time and space complexities.  
It also covers algorithm comparison, graph-based problem solving, and visualization of execution results.

---

## Objective of the Project

The goal of this project is to:
- Understand algorithmic thinking and performance evaluation
- Implement techniques such as recursion, dynamic programming, brute force, and optimization
- Compare algorithms based on execution time and memory usage
- Visualize performance graphs for different input sizes
- Analyze problems using real computational models
